# 🚀 Дашборд мониторинга + TODO-лист на Docker

Это мой первый полноценный DevOps-проект. Он поднимает инфраструктуру из нескольких сервисов, которые общаются друг с другом через Docker-сеть. 

✅ **Мониторинг** — проверяет доступность сайтов в реальном времени 
✅ **TODO-лист** — сохраняет заметки в PostgreSQL даже после перезапуска 
✅ **Всё в одном интерфейсе** — дашборд на Flask 

---

## 🧱 Архитектура проекта

| Компонент       | Технология      | Порт   | Что делает |
|-----------------|-----------------|--------|------------|
| Веб-сервер 1    | Nginx           | 8000   | Статичный сайт |
| Веб-сервер 2    | Nginx           | 8001   | Второй статичный сайт |
| Дашборд         | Python + Flask  | 8004   | Мониторинг + TODO-лист |
| База данных     | PostgreSQL      | 5432   | Хранит заметки |

Все контейнеры общаются через общую сеть `app-network`.
